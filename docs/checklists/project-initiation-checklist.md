# Project Initiation Checklist

Use this checklist at the start of every new project or feature initiative to ensure all initiation requirements are met before moving into planning. See [Project Initiation Guide](../octoacme-project-initiation.md) for full guidance.

---

## One-Pager

- [ ] Project name defined
- [ ] Problem statement written and reviewed
- [ ] Objective / Goal stated in SMART format
- [ ] Success metrics identified and measurable
- [ ] Primary stakeholders listed
- [ ] Suggested timeline and key milestones outlined
- [ ] Quick risks and dependencies noted
- [ ] Proposed team and roles documented
- [ ] One-pager reviewed and signed off by Product Lead

## Stakeholder Alignment

- [ ] Stakeholder list created with names, roles, and communication needs
- [ ] Initial alignment meeting or email sent to sponsor and key stakeholders
- [ ] Stakeholders agree on priority and business need
- [ ] Communication plan (frequency, channel, owner) documented

## Decision Gate

- [ ] Success metrics are clear and agreed upon
- [ ] Stakeholders confirm priority
- [ ] Team availability and resource needs confirmed
- [ ] Go / no-go decision recorded in the project log
- [ ] Project board or repository skeleton created
- [ ] Initial artifacts added to `docs/` or `.copilot/`

---

**Owner:** Project Manager
